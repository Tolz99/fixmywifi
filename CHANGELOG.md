# Changelog

## 0.1.0 (2026-11-18)

First release.

- Wi-Fi scanning on macOS, Linux and Windows (no admin rights needed)
- Home questionnaire (size, rooms, floors, walls, router spot, setup, devices, plan)
- 25+ plain-English rules covering signal, noise, band, channel crowding, width, DFS, Wi-Fi generation,
  link speed, latency, packet loss, speed vs plan, bufferbloat, DNS, security, coverage and hardware
- Room-by-room walk test (`--rooms`)
- Terminal, brief, HTML, Markdown and JSON reports, with network names removed by default
