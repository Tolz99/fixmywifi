# Security

fixmywifi is read-only by design: it runs a handful of standard OS commands, sends pings, DNS queries and a
speed test, and reads your router's public UPnP description. It never changes settings or logs in anywhere.

If you find a way it could leak private information, run something unexpected, or be abused by a malicious
device on the network, please report it privately through
[GitHub security advisories](https://github.com/Tolz99/fixmywifi/security/advisories/new) instead of a public
issue.
